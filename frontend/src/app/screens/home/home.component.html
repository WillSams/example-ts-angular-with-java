About Acme Hotel Reservation System

This is a reference implementation of the Acme Hotel Reservation system built with Angular 17, NgRx, Spring Boot 3, and PostgreSQL.

  • Rooms cannot be double-booked
  • Check-in date must be in the future
  • Total charge = daily rate × number of nights + cleaning fee

Tech Stack: Angular 17 (Standalone Components), NgRx 17, Bootstrap 5, Spring Boot 3.2, Spring for GraphQL, Spring Security (JWT), Spring Data JPA, PostgreSQL
